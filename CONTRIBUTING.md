# Contributing to Signal-Goblin

Thanks for your interest in contributing! Please read the guidelines below to make the process smooth.

How to contribute
- Open an issue to discuss larger changes before implementing.
- Fork the repo and create a feature branch from main (e.g., feature/my-change).
- Write tests where applicable and run the CI locally.
- Open a pull request against main.

Code style
- Follow the existing C++ style in the repository.
- Use CMake for build/test integration.

Commit messages
- Use clear, present-tense messages. Include a short description and rationale when appropriate.

Review process
- All PRs are reviewed. Maintain owner may request changes before merging.

Thank you for contributing!
